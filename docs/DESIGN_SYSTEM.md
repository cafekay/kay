# KH科合视造官网视觉系统

版本：V1.0

## 1. Design Read

KH 官网是面向转介绍客户、企业负责人、品牌市场负责人和商业合作伙伴的创意机构作品站。

它不采用通用企业官网组件体系，而以原生编辑排版、真实案例素材和克制动效构成独立的品牌视觉语言。

核心视觉公式：

> 暗域流光 × 电影感编辑网格 × 克制商业表达

设计参数：

- 版式变化：8/10
- 动效强度：7/10
- 信息密度：3/10

视觉气质：

> 暗而不冷，金而不俗，动而不躁。

## 2. Luminous Matter

“暗域流光”是网站最高优先级的品牌识别，不是背景装饰或一次性 Hero 特效。

### 2.1 光的行为

- 光从深暗空间中生成，而不是贴在界面表面
- 光具有缓慢流动、聚合、折射、拖曳和消散的过程
- 轮廓以柔焦、长曝光和大尺度明暗过渡为主
- 允许局部高光，但不形成刺眼的霓虹边缘
- 每个页面可以改变光的形态，但不能改变光的色温、节奏与空间逻辑

### 2.2 光的角色

- Hero：建立第一印象与品牌记忆
- 页面转场：连接不同内容状态
- 案例显影：引导作品从暗处进入清晰状态
- 交互反馈：通过亮度、遮罩或折射变化回应用户操作

### 2.3 禁止表达

- 传统黑金商务风
- 金色发光字
- 粒子宇宙和星空背景
- 高频闪烁、光污染和霓虹描边
- 无空间层次的普通金色渐变
- 为展示技术而加入的复杂 WebGL 或 3D 特效

## 3. Color System

### 3.1 Core Palette

| 语义 | 色值 | 主要用途 |
| --- | --- | --- |
| Deep Void | `#090907` | 页面主背景、Hero 暗域 |
| Carbon Brown | `#17120D` | 次级背景、媒体遮罩、悬浮层 |
| Umber Depth | `#3A2717` | 光影过渡、局部层次 |
| Burnished Amber | `#8A5B2B` | 克制强调、细线、交互过渡 |
| Luminous Amber | `#D39A50` | 流光高光、关键焦点，禁止大面积平铺 |
| Warm Ivory | `#EEE7DC` | 主文字、Logo 反白、重要标题 |

### 3.2 使用比例

- 深色暗域：约 75%
- 作品与影像内容：约 20%
- 琥珀光及强调：不超过 5%

比例用于控制整体感受，不作为逐屏机械配额。

### 3.3 色彩约束

- 页面保持统一暗色主题，不在中途切换为大面积浅色模式
- 暖琥珀是唯一主强调色
- 主文字使用暖象牙白，避免纯白造成生硬反差
- 禁止企业蓝、高饱和蓝紫、营销红和多色按钮
- 禁止把琥珀色当作普通金色 UI 色使用

## 4. Typography

### 4.1 字体组合

- 英文展示标题：Barlow Condensed
- 中文标题与正文：Source Han Sans SC（思源黑体）
- 数字、年份与功能性元信息：Inter

字体优先采用可合法免费商用并可自行托管的文件，生产环境不依赖境外字体 CDN。

### 4.2 排版性格

- 英文标题使用收窄字面形成电影海报和建筑事务所式纵向张力
- 中文保持轻至常规字重，避免粗黑标题造成传统广告感
- 大标题依靠比例、留白和位置建立力量，不依赖发光、描边或渐变字
- 正文行宽保持克制，单行中文建议约 18-30 字
- 英文大写可使用适度字距，但禁止每个区块都采用相同的小号大写眉题

### 4.3 字重建议

- Hero 英文：300-400
- 中文主标题：300-500
- 正文：300-400
- 功能文字：400-500

## 5. Spatial Composition

### 5.1 网格

- Desktop：12 栏编辑网格
- Tablet：8 栏网格
- Mobile：4 栏网格
- 内容最大宽度以 1440px 视觉稿为基准，不让所有内容机械居中
- 案例图片允许跨栏、错位和不等比例组合

### 5.2 空间感

- 使用大面积负空间建立专业距离感
- 每一屏只承担一个主要叙事任务
- 标题、说明和作品图之间形成明确主次，不平均分配视觉重量
- 允许局部密集，但密集内容之后必须出现呼吸区
- 移动端重新编排内容顺序，不将桌面布局简单缩小

### 5.3 版式约束

- 禁止连续使用相同的左右图文结构
- 禁止四项能力直接做成等宽、等高、带阴影的普通卡片
- 禁止每个区块重复“英文眉题 + 大标题 + 右侧小段落”的模板
- 禁止用装饰网格线、编号和状态圆点伪造设计感
- Hero 必须在首屏形成完整画面，核心文字和主要入口无需向下滚动即可看到

## 6. Shape and Material

- 页面主体以锐利边缘和完整画幅为主
- 案例图片默认不使用卡片阴影
- 圆角仅用于确有交互含义的媒体容器或控制项，并保持统一尺度
- 分组优先依靠留白、比例和轻微色差，不依赖大量边框和悬浮卡片
- 半透明材质只允许用于覆盖在动态影像上的导航或控制层，不能发展为通用玻璃拟态

## 7. Motion Principles

### 7.1 动效目的

每个动效必须至少完成一种任务：建立层级、推进叙事、回应交互或说明状态变化。

### 7.2 核心动效

- 流光缓慢循环与呼吸
- 媒体从柔焦、遮蔽或暗部进入清晰状态
- 页面内容以小幅位移和透明度变化显影
- 案例悬停以画面变化为主，文字反馈为辅
- 页面转场保持连贯，不制造等待感

### 7.3 节奏

- 微交互：160-260ms
- 内容显影：500-900ms
- 页面转场：600-1000ms
- 环境流光：6-14s 缓慢循环，避免明显重复节点

### 7.4 性能与可访问性

- 主要动画只改变 `transform` 与 `opacity`
- 不通过滚动事件逐帧更新界面状态
- 尊重 `prefers-reduced-motion`
- 减少动态效果时，流光降级为已确认的静态光影画面或低频交叉淡化
- 首屏视频必须提供 poster，并在加载失败时保持构图完整

## 8. Media Direction

### 8.1 首页流光素材

已确认的视觉基准：

- `assets/visuals/hero-dappled-light-v1.png`
- `assets/visuals/hero-luminous-caustics-v1.png`

首图方向以大尺度、柔焦、暖琥珀光斑在深暗空间中的斜向流动为主，不使用尖锐光纤或高密度粒子。

### 8.2 案例素材

- 使用真实项目图片、视频画面和品牌设计成果
- 首页案例说明保持最少，图片承担主要表达
- 不使用普通图库人物、握手、办公室和随机抽象素材
- 不以低质量视频截图替代正式封面
- 同一案例的色彩可保留自身特征，但展示节奏必须服从网站整体暗域框架

## 9. Responsive Direction

- Desktop：强调跨栏构图、尺度对比与电影画幅
- Tablet：保留错位关系，减少并列信息
- Mobile：单列叙事优先，保留光影焦点和作品完整比例
- Hero 使用动态视口高度，避免移动浏览器地址栏造成跳动
- 移动端流光视频使用独立裁切和轻量编码，不直接缩放桌面版本

## 10. Visual Acceptance Checklist

交付前必须检查：

- 是否第一眼能感知流动的光，而不是普通黑金配色
- 是否仍像创意机构作品站，而不是广告公司模板
- 是否由真实案例主导视觉
- 是否有足够留白与明确视觉层级
- 是否避免等宽卡片、重复版式和装饰性标签
- 是否在移动端保持作品构图与品牌气质
- 是否在关闭动画或视频失败时仍成立
- 是否没有为了特效牺牲首屏速度
